# Cairn Coast: Low Water

[![make.fun competition](https://make.fun/badge/gta6-01.svg)](https://make.fun)
[![Live rank](https://make.fun/badge/gta6-01/BangDills/cairn-coast-low-water/rank.svg)](https://make.fun)
[![Live reward](https://make.fun/badge/gta6-01/BangDills/cairn-coast-low-water/reward.svg)](https://make.fun)

An original, offline, third-person harbor crime game. Rowan Vale returns to a city whose port authority is buying its neighborhoods with stolen relief money. Ferry steward Inez and mechanic Sora have pieces of a ledger. Five staged jobs take the evidence from the ferry market to an archive convoy at Low Water Quay.

This game was built for the [Make GTA 6 bounty](https://make.fun/bounty/gta6-01).

## Play locally

Requires a desktop browser with WebGL 2, keyboard, and mouse. There is no build step and no package installation for the game or its server.

```sh
node serve.mjs
# Open http://127.0.0.1:8087
```

Any static HTTP server rooted at `game/` works. Opening `index.html` directly as a `file:` URL is unsupported because the game uses ES modules. All runtime scripts, geometry, textures, and audio are local or generated by the game. No login or network service is needed.

## Controls

| Input | Action |
| --- | --- |
| WASD | Walk; throttle, brake/reverse, and steer in a vehicle |
| Shift | Sprint on foot |
| E | Enter, steal, or leave a nearby vehicle; slow down before exiting |
| F | Talk, collect, shop, deliver; hold for relay uploads |
| Mouse + left click | Aim and attack |
| Q / 1 / 2 / 3 | Cycle weapons / hands / pistol / purchased SMG |
| R | Reload |
| Space | Jump on foot; handbrake while driving |
| Right mouse drag / left-right arrows | Orbit camera |
| C | Center camera behind your direction |
| M | City map, job calls, retry, and abandon |
| V | Toggle original radio instrumental |
| F5 | Save while the patrol is clear |
| Escape | Pause, settings, controls, and save |

Begin on foot at the ferry market. Collect the envelope at the yellow marker, then take the copper Kestrel to Tern Motors. The car beside the market is yours. Other vehicles may draw police attention.

You can fire from a vehicle. It absorbs most incoming fire, but those hits damage the car too; another ride can make a better getaway. The archive truck's cargo armor resists patrol rounds, and its weight helps in a collision. Fire back at close pursuers before trying to disappear. For relay uploads, hold F while moving inside the yellow ring. During a pursuit, use buildings to break sight and long clear streets to gain distance. Standing beside a live officer risks arrest.

## The city and its systems

- Walk or drive through Ferry Strand, the inland blocks, Foundry, North Heights, and Low Water. Traffic follows the street graph. Pedestrians wander and flee threats.
- Five vehicle types have different speed, acceleration, steering, durability, and mass. Cars can be stolen, damaged, repaired, or destroyed.
- Five wanted tiers add pursuit and interception, junction cordons from tier three, and air search from tier four. Dispatch shows whether you are in sight, being searched for, or cooling down. Break sightlines behind buildings. An unseen vehicle swap shortens the search; garage plates can lower an unseen pursuit.
- Five story jobs include an envelope run, a tracked van theft, an on-foot port firefight, three timed relay uploads, and a moving archive-truck interception. Each has actual stages, rewards, and retry behavior. The story remains complete when you return to free roam.
- A four-checkpoint street sprint and a three-drop delivery round can be repeated. Twelve hidden dock cases reward exploration.
- Tern Motors sells measured handling, engine, and chassis upgrades. The clinic sells health and armor; Foundry Supply sells ammunition and an SMG. Room 9 restores health and armor and saves progress.
- Cars, people, city architecture, signs, ocean, effects, synthesized engines, sirens, weapon sounds, and the radio instrumental are original procedural work. Three.js is the only game library.

## Saves and settings

Completed jobs, money, standing, upgrades, ammunition, activity records, collected cases, health, armor, and location are stored in this browser's `localStorage`. Save from pause, F5, or Room 9 while clear. Jobs and purchases also save when eligible. Reloading starts on foot; traffic and vehicles reset. A job in progress restarts from its briefing, rather than restoring the live pursuit. There is one local save slot. Starting a new story asks before replacing it.

Pause offers sound, reduced camera motion, and Shadows / Performance / Automatic graphics. Automatic can reduce resolution and disable map shadows on a slow renderer. Lightweight contact shadows remain in Performance mode. Audio starts after a user gesture and the entire game can be played muted.

## Packaging

`main.ts` is a Node standard-library-only entrypoint. Packaging requires Node 22.18 or later, verified here with Node 22.23.4. It copies the selected game and actual browser screenshots, then builds the dossier with the unchanged official kit helper.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.mjs out/game
```

No gameplay runs during packaging; fixed source and screenshots produce identical output bytes. The repository does not contain credentials, an API integration, or an inference-time model call.

## Testing and limits

`tests/systems.mjs` runs deterministic domain checks using Node and the bundled engine. Browser test scripts use an already installed Playwright package and Chromium at the paths named in those scripts; those development tools are not game dependencies. They exercise real keyboard/mouse input, block non-loopback requests, and use a read-only snapshot for assertions. See `QA.md` for the final verified scope and limitations.

The city is a compact authored sandbox with exterior spaces, simplified collision and NPC navigation. It has no building interiors, multiplayer, touch controls, voice acting, or cloud saves. The camera and HUD target desktop play. A software SwiftShader browser was usable in Performance mode but did not meet the supplied brief's 33 ms p95 target; hardware-accelerated performance has not been measured. No top-ten result is claimed.
